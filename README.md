### 👨‍💻 Sobre Mim

Profissional focado em criar soluções que conectam **análise de dados, engenharia financeira e automação de processos**. O meu objetivo principal é eliminar tarefas manuais repetitivas, reduzir custos operacionais e fornecer visibilidade clara sobre os indicadores essenciais do negócio.

Atuo no desenvolvimento de ecossistemas ponta a ponta:
- 📈 **Business Intelligence & Analytics:** Criação de dashboards interativos (Power BI, Streamlit) focados em usabilidade e tomada de decisão rápida.
- ⚙️ **Automação Corporativa:** Integração de planilhas, bancos de dados e APIs via Python e Google Apps Script.
- 🗄️ **Modelagem de Dados:** Estruturação de consultas otimizadas e pipelines de ETL para garantir a consistência das informações.
